# Aziz Karaborni Portfolio

Static portfolio website tailored for GitHub Pages.

## Deploy on GitHub Pages

1. Create a repository named `Azizos126926.github.io` (or use your existing one).
2. Upload the files from this folder to the root of the repository.
3. In GitHub, go to **Settings → Pages**.
4. Set the source to **Deploy from a branch** and choose the `main` branch.
5. Your website will be published automatically.

## Included files

- `index.html`
- `style.css`
- `script.js`
- `CV_Aziz_Karaborni.pdf`
